📱 iPhone Install & Two-Phone Sync

How to install on both iPhones:
  1. Host this single HTML file on a free static link (e.g., Netlify Drop, GitHub Pages, or Vercel) or open the shared link in Safari.
  2. Tap the Share button (square with upward arrow) at the bottom of Safari.
  3. Scroll down and tap Add to Home Screen → Add. It launches full-screen like a native iOS app!

Paste a free Firebase Realtime Database URL (e.g. https://your-app.firebaseio.com) and use the same Room Code on both iPhones to sync every match automatically in real time.
